# Scrcpy 一键投屏脚本

基于 [scrcpy](https://github.com/Genymobile/scrcpy) 的 Windows 投屏脚本，支持 USB 有线投屏、无线连接、无线配对和 ADB 服务管理。双击根目录的 `.bat` 文件即可使用，无需安装 Python 或执行构建。

## 目录结构

```text
项目目录/
├─ scrcpy/                         scrcpy 官方程序，升级时覆盖这里
│  ├─ scrcpy.exe
│  ├─ scrcpy-server
│  ├─ adb.exe
│  └─ DLL、图标、许可证等官方配套文件
├─ scripts/                        本项目公共脚本
│  ├─ _scrcpy.ps1                   连接、设备选择和启动逻辑
│  └─ .last_device                  自动生成的上次无线地址
├─ 00.启动adb命令窗口.bat
├─ 01.终止adb服务.bat
├─ 1.有线下配置无线调试.bat
├─ 2.启动adb无线连接并投屏.bat
├─ 3.无线直接投屏.bat
├─ 4.启动adb有线连接并投屏.bat
├─ 5.无线调试配对.bat
└─ README.md
```

`scrcpy/` 和 `scripts/` 放在同一级，保留这两个文件夹的名称。根目录另有 Git 版本管理文件。

## 功能介绍

| 启动脚本 | 功能 |
| --- | --- |
| `00.启动adb命令窗口.bat` | 打开可直接输入 adb 命令的窗口，并列出当前设备 |
| `01.终止adb服务.bat` | 关闭本项目的投屏窗口并停止 ADB 服务 |
| `1.有线下配置无线调试.bat` | 通过 USB 开启手机的 TCP/IP 5555 调试，验证无线连接并记住地址 |
| `2.启动adb无线连接并投屏.bat` | 输入手机 IP 和连接端口，连接后立即投屏；回车可复用上次地址 |
| `3.无线直接投屏.bat` | 已在线时直接无线投屏；未在线时尝试上次成功地址 |
| `4.启动adb有线连接并投屏.bat` | 等待 USB 设备并开始有线投屏 |
| `5.无线调试配对.bat` | 使用 Android 11 及以上系统的无线调试配对码进行配对 |

脚本会过滤离线、未授权设备，多台可用设备时提示选择。无线与 USB 设备分别选择，避免投错设备；连接失败自动重试，并保存上次成功的无线连接地址。支持中文输出及带中文、空格的项目路径。

## 怎么使用

### USB 有线投屏

1. 手机开启“开发者选项 → USB 调试”。
2. 用支持数据传输的 USB 线连接电脑，解锁手机并允许本机调试。
3. 双击 `4.启动adb有线连接并投屏.bat`，等待投屏窗口打开。

### 无线投屏：手机自带无线调试

适用于 Android 11 及以上、提供“无线调试”功能的手机。手机和电脑需要处于能互相访问的同一局域网。

**首次配对：**

1. 手机打开“开发者选项 → 无线调试 → 使用配对码配对设备”。
2. 双击 `5.无线调试配对.bat`，输入配对弹窗里的 `IP:配对端口` 和六位配对码。
3. 回到手机“无线调试”首页，查看 `IP:连接端口`。
4. 双击 `2.启动adb无线连接并投屏.bat`，输入该连接地址。

**日常使用：** 已连接时双击 `3.无线直接投屏.bat`。如果手机重启、切换 Wi-Fi 或关闭过无线调试，连接端口可能变化，用 `2.` 输入手机当前的连接地址即可。只有配对失效时才需要重新运行 `5.`。

> 配对端口和连接端口是两个不同的端口。手机自带无线调试通常使用动态端口，不要直接填 5555。

### 无线投屏：通过 USB 开启

适用于希望通过数据线先开启无线连接的情况。

1. 连接 USB，解锁手机并允许 USB 调试，同时保持手机连接 Wi-Fi。
2. 双击 `1.有线下配置无线调试.bat`。
3. 看到无线连接验证成功后，拔掉 USB 线。
4. 双击 `3.无线直接投屏.bat`；也可用 `2.` 输入手机 `IP:5555`。

这种方式在手机重启后可能需要重新接线运行 `1.`。

### 关闭投屏与 ADB

关闭投屏窗口即可结束本次投屏。需要停止 ADB 服务时运行 `01.终止adb服务.bat`；使用同一 ADB 服务的其他 Android 工具也会断开连接。

### 可选参数

日常使用直接双击即可。`2.`、`3.`、`4.` 也支持在命令行追加 scrcpy 参数。以下是 PowerShell 示例：

```powershell
# 静音投屏，限制帧率
& '.\3.无线直接投屏.bat' --no-audio --max-fps=60

# 限制分辨率，设置窗口标题
& '.\3.无线直接投屏.bat' --max-size=1280 '--window-title=我的手机'

# 指定无线地址，跳过输入提示
& '.\2.启动adb无线连接并投屏.bat' --address 192.168.1.100:42215

# 最多等待 USB 设备 30 秒
& '.\4.启动adb有线连接并投屏.bat' --usb-timeout 30
```

`--address` 也可用于 `3.` 和 `5.`，用于 `5.` 时填写配对地址。`--usb-timeout` 可用于 `1.` 和 `4.`，范围为 0～300 秒。自动化调用可追加 `--no-pause`，错误退出时不等待回车。其他参数见 [scrcpy 官方文档](https://github.com/Genymobile/scrcpy/tree/master/doc)。

## 怎么更新

### 更新 scrcpy 主程序

本项目目前随附 scrcpy **5.0.1 / Windows x64**，ADB **37.0.1**。升级 scrcpy 不需要改根目录入口或 `scripts/`。

1. 关闭投屏窗口，运行 `01.终止adb服务.bat`，避免程序文件被占用。
2. 从 [scrcpy 官方发布页](https://github.com/Genymobile/scrcpy/releases) 下载与你电脑架构匹配的 Windows 压缩包，普通 Intel / AMD 64 位电脑选择 `scrcpy-win64-版本号.zip`。
3. 打开压缩包中的版本文件夹，将其内部的**全部文件**解压到本项目的 `scrcpy/`，选择覆盖同名文件。
4. 确认实际路径是 `scrcpy/scrcpy.exe`，不要多套一层 `scrcpy/scrcpy-win64-版本号/`。
5. 运行下面的命令确认版本，然后用 `2.` 重新连接手机或用 `4.` 有线投屏。

```powershell
.\scrcpy\scrcpy.exe --version
.\scrcpy\adb.exe version
```

建议更新前把整个 `scrcpy/` 复制一份留作回退。使用官方发布页提供的 `SHA256SUMS.txt` 可核对下载包的 SHA-256。务必整体更新客户端、服务端、ADB 和 DLL，不要只替换 `scrcpy.exe`。

如果新版本改变了 DLL 文件名，覆盖后旧 DLL 可能仍留在目录里。需要干净升级时，备份旧目录，再创建同名 `scrcpy/` 并解压新版全部文件即可。脚本按 DLL 家族检查依赖，没有写死 SDL / FFmpeg 的版本后缀；若上游未来改变命令参数或程序布局，仍需更新本项目脚本。

### 更新本项目脚本

下载本项目的新版本，覆盖根目录的 `.bat`、README 和 `scripts/` 中的公共脚本即可。保留自己已经更新的 `scrcpy/` 主程序目录，以及 `scripts/.last_device` 地址缓存。`tests/` 也随脚本版本一起更新。

从旧的平铺目录升级时，请把官方程序文件放进 `scrcpy/`、公共脚本放进 `scripts/`，并使用配套的新入口文件，避免混用新旧路径。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 提示找不到程序或 DLL | 确认完整官方包已放进 `scrcpy/`，且没有多套版本文件夹 |
| 设备显示 `unauthorized` | 解锁手机并允许本机 USB 调试，必要时重新授权 |
| 设备显示 `offline` 或无线连接失败 | 检查当前连接端口、同一局域网、防火墙和路由器隔离设置，再用 `2.` 重连 |
| 配对成功但连接失败 | 使用无线调试首页的连接端口，不要使用配对弹窗的端口 |
| 有线检测不到手机 | 检查数据线、USB 调试授权和电脑驱动 |
| 图像花屏或硬解异常 | 运行投屏脚本时追加 `--hwdec=disabled` 尝试软件解码 |
| 修改脚本后中文乱码 | `.bat` 保存为 ASCII、CRLF；`scripts/_scrcpy.ps1` 保存为 UTF-8 带 BOM |
| 想清除上次无线地址 | 删除 `scripts/.last_device`，下次成功连接后会重新生成 |
